# Artigos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Criar `/artigos` e `/artigos/[slug]` com conteúdo MDX server-side, drafts seguros, SEO/GEO/AEO por rota e três rascunhos jurídicos, sem modificar o JSON-LD global já validado em produção.

**Architecture:** Arquivos em `content/artigos` são lidos por um repositório tipado e validados com Zod. As rotas App Router consomem esse contrato por Server Components, pré-renderizam somente conteúdos publicados e geram metadata/JSON-LD próprios. Componentes client-side ficam limitados aos elementos já interativos do projeto.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, Tailwind CSS 4, `next-mdx-remote@6.0.0`, `gray-matter@4.0.3`, Zod 4, Vitest 5, npm.

**Spec:** `docs/superpowers/specs/2026-09-03-artigos-design.md`

Create `src/lib/artigos/schema.ts`:

```ts
import { z } from 'zod'

const dateOnly = z.string()
  .regex(/^\d{4}-\d{2}-\d{2}$/)
  .refine((value) => {
    const parsed = new Date(`${value}T00:00:00.000Z`)
    return !Number.isNaN(parsed.valueOf()) && parsed.toISOString().slice(0, 10) === value
  }, 'Informe uma data válida no formato YYYY-MM-DD')

export const ArticleFrontmatterSchema = z.object({
  id: z.string().min(1),
  title: z.string().min(10),
  slug: z.string().regex(/^[a-z0-9]+(?:-[a-z0-9]+)*$/),
  description: z.string().min(30).max(180),
  category: z.string().min(2),
  tags: z.array(z.string().min(2)).min(1),
  keywords: z.array(z.string().min(2)).min(1),
  coverImage: z.string().regex(/^\/images\/.+\.(?:avif|webp|png|jpe?g)$/),
  coverImageAlt: z.string().min(10),
  author: z.literal('CBM Agro e Gestão de Passivos'),
  draft: z.boolean(),
  publishedAt: dateOnly.nullable(),
  updatedAt: dateOnly.nullable(),
}).superRefine((value, ctx) => {
  if (!value.draft && !value.publishedAt) {
    ctx.addIssue({ code: 'custom', path: ['publishedAt'], message: 'publishedAt é obrigatório para publicação' })
  }
  if (!value.draft && !value.updatedAt) {
    ctx.addIssue({ code: 'custom', path: ['updatedAt'], message: 'updatedAt é obrigatório para publicação' })
  }
  if (value.publishedAt && value.updatedAt && value.updatedAt < value.publishedAt) {
    ctx.addIssue({ code: 'custom', path: ['updatedAt'], message: 'updatedAt não pode ser anterior a publishedAt' })
  }
})

export type ArticleFrontmatter = z.infer<typeof ArticleFrontmatterSchema>
export type ArticleEnvironment = 'development' | 'test' | 'production'

export interface ArticleSummary extends ArticleFrontmatter {
  href: `/artigos/${string}`
  readingTimeMinutes: number
}

export interface ArticleDocument extends ArticleSummary {
  body: string
  plainText: string
  sourcePath: string
}
```
